# 🌍 LLM Translate Chrome 插件

一个强大的浏览器翻译插件，使用 LLM 进行精准翻译，支持自动翻译和按需翻译两种模式。

## ✨ 功能特点

### 1. 🔄 自动翻译
- **日文自动翻译**：检测到日文内容时自动翻译（始终启用）
- **英文可选翻译**：可在设置中选择是否自动翻译英文内容
- **智能检测**：自动识别页面主要语言，避免重复翻译

### 2. 👆 快捷键 + 悬停翻译
- 按住指定的快捷键（Alt/Ctrl/Shift/Meta）
- 鼠标悬停在段落上 2 秒
- 段落自动翻译显示

### 3. 🤖 LLM 驱动翻译
- 支持 OpenAI 兼容 API（如 OpenAI、Ollama、其他开源 LLM）
- 自定义 Base URL、Model ID 和 API Key
- 高质量的语义翻译

### 4. 📝 灵活翻译选项
- 一键翻译整个页面
- 支持多种目标语言（中文、English、日本語、한국어）
- 可在任何网站单独启用/禁用

## 🚀 快速开始

### 安装步骤

1. **准备 API 凭证**
   - OpenAI: 从 https://platform.openai.com/api-keys 获取 API Key
   - 或使用其他 OpenAI 兼容的 LLM 服务

2. **安装插件**
   - 在 Chrome 中打开 `chrome://extensions/`
   - 启用"开发者模式"（右上角）
   - 点击"加载已解压的扩展程序"
   - 选择此文件夹

3. **配置 API 设置**
   - 点击插件图标打开设置面板
   - 填写 Base URL、API Key、Model ID
   - 选择偏好的目标语言和翻译模式
   - 点击"保存设置"

### 配置示例

#### OpenAI
```
Base URL: https://api.openai.com/v1
Model ID: gpt-4o (或 gpt-3.5-turbo)
API Key: sk-xxxxxxxxxxxx
```

#### Ollama（本地 LLM）
```
Base URL: http://localhost:11434/v1
Model ID: llama2 (或您安装的模型名)
API Key: ollama (可任意填写)
```

#### 其他 OpenAI 兼容 API
```
Base URL: https://your-api-provider.com/v1
Model ID: 您的模型名
API Key: 您的 API Key
```

## 📖 使用指南

### 自动翻译
- 页面加载完成后，插件会自动检测语言
- 如果是日文或启用了自动翻译的英文，会自动翻译页面内容
- 翻译的内容会显示在原文下方，用蓝色块标记

### 手动翻译（快捷键模式）
1. 按住设置中配置的快捷键（默认 Alt）
2. 将鼠标悬停在要翻译的段落上
3. 2 秒后段落自动翻译
4. 段落会有蓝色边框高亮显示

### 翻译整个页面
- 在插件面板中点击"翻译整个页面"按钮
- 所有可翻译元素会依次翻译
- 翻译进度在插件面板显示

## ⚙️ 高级设置

### 翻译范围
插件会翻译以下 HTML 元素：
- 段落: `<p>`
- 标题: `<h1>` - `<h6>`
- 列表项: `<li>`
- 表格: `<td>`, `<th>`
- 引用: `<blockquote>`
- 文章: `<article>`, `<section>`
- 自定义内容容器: `.post-content`, `.article-content`

### 温度参数
翻译采用较低的温度值 (0.3)，确保翻译的一致性和准确性。

### 批处理
- 页面翻译采用批处理模式，每次 3 个元素
- 避免过度调用 API，节省配额

## 🔒 隐私与安全

- **本地存储**：所有配置仅保存在本地浏览器
- **不存储翻译历史**：不会保存任何翻译内容
- **API Key 安全**：密码字段显示为 masked，仅用于 API 调用
- **HTTPS 推荐**：建议使用 HTTPS 的 API 端点

## 🐛 故障排除

### 翻译失败

**错误提示："请先在插件设置中配置API信息"**
- 检查是否填写了所有必需的字段：Base URL、API Key、Model ID

**错误提示："API请求失败 (401)"**
- API Key 不正确
- 联系 API 提供商验证凭证

**错误提示："API请求失败 (429)"**
- 当前 API 配额已用尽
- 等待配额重置或升级 API 计划

**错误提示："网络错误"**
- 检查网络连接
- 确认 Base URL 正确且可访问
- 检查 API 提供商的服务状态

### 插件不工作

1. 确保插件已启用
2. 刷新页面
3. 检查浏览器控制台（F12）查看错误信息
4. 尝试重新加载插件（在 `chrome://extensions/` 中）

### 翻译质量不佳

- 尝试更换模型（如 `gpt-4o` 通常质量更好）
- 检查源文本的语言是否正确识别
- 调整目标语言

## 📋 常见问题

**Q: 可以离线使用吗？**
A: 不可以。需要 API 连接才能进行翻译。

**Q: 支持哪些语言？**
A: 取决于您选择的 LLM 模型。大多数现代模型支持 100+ 种语言。

**Q: 会自动翻译其他语言吗？**
A: 默认仅自动翻译日文和可选的英文。其他语言可通过快捷键手动翻译。

**Q: 翻译费用如何计算？**
A: 根据您 API 服务商的定价。通常按输入/输出 token 数计费。
